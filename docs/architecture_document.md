# Basana 项目架构文档

## 项目概述

**Basana** 是一个基于 Python 的**异步事件驱动**算法交易框架，专注于加密货币交易。项目采用模块化设计，提供完整的回测和实时交易功能。

### 核心特性
- **事件驱动架构**：基于异步事件的生产者-消费者模式
- **回测系统**：支持历史数据回测，可测试交易策略
- **实时交易**：支持 Binance 和 Bitstamp 交易所的实时交易
- **异步I/O**：基于 asyncio 的高性能异步处理
- **模块化设计**：清晰的组件分离和职责划分

## 核心模块详解

### 1. 事件系统 (Event System)

#### 1.1 事件基类 (Event)
```python
class Event:
    """事件基类 - 所有事件类型的父类"""
```
- **功能**：定义事件的基本结构，确保所有事件都有时间戳
- **核心属性**：
  - `when`：事件发生时间（必须包含时区信息）
- **验证**：强制要求时间戳包含时区信息，防止时区混淆

#### 1.2 生产者 (Producer)
```python
class Producer:
    """生产者基类 - 负责生成和推送事件"""
```
- **生命周期方法**：
  - `initialize()`：初始化阶段，建立连接和加载配置
  - `main()`：主循环阶段，持续生成事件
  - `finalize()`：清理阶段，释放资源
- **设计模式**：模板方法模式，子类实现具体逻辑

#### 1.3 事件源 (EventSource)
```python
class EventSource(metaclass=abc.ABCMeta):
    """事件源抽象基类 - 提供事件的接口定义"""
```
- **核心方法**：`pop()` - 获取下一个事件
- **支持类型**：
  - 主动事件源（关联生产者）
  - 被动事件源（从队列、文件等读取）

#### 1.4 FIFO队列事件源 (FifoQueueEventSource)
```python
class FifoQueueEventSource(EventSource):
    """先进先出队列事件源实现"""
```
- **底层存储**：使用 `collections.deque` 实现
- **操作**：`push()` 入队，`pop()` 出队
- **应用场景**：内存事件缓冲、事件回放

### 2. 事件分发器 (Event Dispatcher)

#### 2.1 核心组件
- **EventMultiplexer**：事件多路复用器，管理多个事件源并按时间顺序检索事件
- **SchedulerQueue**：调度作业优先级队列，基于最小堆实现
- **TaskPool**：异步任务池，管理并发事件处理

#### 2.2 事件分发器基类 (EventDispatcher)
```python
class EventDispatcher(metaclass=abc.ABCMeta):
    """事件分发器抽象基类"""
```
- **核心职责**：
  - 管理事件源和事件处理器的注册关系
  - 按时间顺序调度和执行事件
  - 管理异步任务的生命周期
  - 提供调度作业功能

- **关键方法**：
  - `subscribe()`：订阅特定事件源
  - `subscribe_all()`：订阅所有事件（全局嗅探器）
  - `schedule()`：调度定时作业
  - `run()`：执行事件分发循环

#### 2.3 回测分发器 (BacktestingDispatcher)
```python
class BacktestingDispatcher(EventDispatcher):
    """回测场景的事件分发器"""
```
- **时间语义**：使用最后处理的事件时间作为"当前时间"
- **执行顺序**：严格按时间顺序处理事件
- **特性**：支持事件时间验证，确保时间顺序正确

#### 2.4 实时分发器 (RealtimeDispatcher)
```python
class RealtimeDispatcher(EventDispatcher):
    """实时交易场景的事件分发器"""
```
- **时间语义**：使用当前UTC时间作为"当前时间"
- **空闲处理**：支持空闲处理器，避免CPU空转
- **事件顺序**：验证同一事件源的事件顺序

### 3. 数据模型

#### 3.1 交易对 (Pair)
```python
@dataclasses.dataclass(frozen=True)
class Pair:
    """交易对数据类"""
```
- **字段**：`base_symbol`（基础货币），`quote_symbol`（计价货币）
- **特性**：不可变数据类，确保线程安全

#### 3.2 K线数据 (Bar)
```python
class Bar:
    """K线（蜡烛图/OHLC）数据结构"""
```
- **字段**：开盘价、最高价、最低价、收盘价、成交量
- **验证**：价格逻辑验证（最高价≥最低价等）

#### 3.3 K线事件 (BarEvent)
```python
class BarEvent(Event):
    """K线事件"""
```
- **关联**：包含Bar实例和发生时间

### 4. 工具组件

#### 4.1 任务管理 (TaskGroup & TaskPool)
- **TaskGroup**：任务组管理，支持批量取消
- **TaskPool**：异步任务池，控制并发数量

#### 4.2 数值处理
- `round_decimal()`：十进制数四舍五入
- `truncate_decimal()`：十进制数截断

#### 4.3 网络工具
- `use_or_create_session()`：HTTP会话管理
- `no_raise()`：异常安全上下文管理器

## 回测模块架构

### 1. 回测交易所 (Exchange)
```python
class Exchange:
    """回测交易所实现"""
```

#### 1.1 核心组件
- **AccountBalances**：账户余额管理
- **Prices**：价格管理，支持买卖价差
- **OrderManager**：订单管理
- **LoanManager**：借贷管理
- **Config**：配置管理

#### 1.2 订单类型支持
- **市价单 (Market Order)**：立即以最优价格成交
- **限价单 (Limit Order)**：指定价格成交
- **止损单 (Stop Order)**：触发后转为市价单
- **止损限价单 (Stop Limit Order)**：触发后转为限价单

#### 1.3 高级功能
- **自动借贷**：资金不足时自动借款
- **自动还款**：订单成交后自动还款
- **流动性策略**：模拟市场冲击影响
- **费用策略**：支持各种手续费计算

### 2. 订单管理 (OrderManager)

#### 2.1 订单生命周期
1. **创建**：验证参数，创建订单
2. **处理**：根据市场数据执行订单
3. **成交**：生成成交记录，更新余额
4. **取消**：手动或自动取消订单

#### 2.2 订单事件
- **OrderEvent**：订单状态变更事件
- **Fill**：订单成交记录

### 3. 借贷管理 (LoanManager)

#### 3.1 借贷策略
- **NoLoans**：无借贷策略
- **其他策略**：支持自定义借贷逻辑

#### 3.2 借贷生命周期
- **创建**：根据需求创建贷款
- **计息**：按策略计算利息
- **还款**：手动或自动还款

## 8. 核心设计模式和架构原则

### 8.1 事件驱动架构
- **生产者-消费者模式**：事件源生产事件，处理器消费事件
- **观察者模式**：事件分发器通知注册的处理器
- **策略模式**：费用策略、流动性策略等可插拔

### 8.2 异步编程模型
- **asyncio**：基于Python原生异步框架
- **任务管理**：使用TaskGroup和TaskPool管理并发
- **非阻塞I/O**：所有网络操作都是异步的

### 8.3 模块化设计
- **单一职责**：每个模块有明确的职责
- **依赖注入**：通过上下文对象传递依赖
- **接口隔离**：抽象基类定义清晰的接口

### 8.4 错误处理
- **结构化日志**：使用结构化消息记录错误
- **异常安全**：使用上下文管理器确保资源释放
- **优雅停止**：支持信号处理和优雅停止

## 9. 配置与扩展

### 1. 配置管理
- **交易对信息**：精度、最小交易量等
- **符号信息**：各货币的精度设置
- **默认配置**：提供合理的默认值

### 2. 扩展点
- **事件源**：可实现自定义事件源
- **事件处理器**：可注册任意异步函数
- **策略**：可自定义费用、流动性、借贷策略

## 性能考虑

### 1. 内存管理
- **事件队列**：使用高效的双端队列
- **任务池**：限制并发任务数量
- **预取机制**：事件多路复用器的预取优化

### 2. 时间处理
- **时区感知**：所有时间都包含时区信息
- **时间排序**：确保事件按正确时间顺序处理
- **性能优化**：使用最小堆管理调度作业

## 使用示例

### 1. 回测示例
```python
# 创建回测分发器
dispatcher = backtesting_dispatcher()

# 创建回测交易所
exchange = Exchange(dispatcher, initial_balances={"USDT": Decimal("1000")})

# 添加K线数据源
exchange.add_bar_source(bar_source)

# 注册策略
dispatcher.subscribe(bar_source, strategy)

# 运行回测
await dispatcher.run()
```

### 2. 实时交易示例
```python
# 创建实时分发器
dispatcher = realtime_dispatcher()

# 创建交易所客户端
client = BinanceSpot(api_key, api_secret)

# 注册事件处理器
dispatcher.subscribe(trade_source, trade_handler)

# 启动实时交易
await dispatcher.run()
```
